# Все проекты, включая SYNKRA: синхронизация ПК и ноутбука

Эта инструкция настраивает одну общую папку со всеми нашими проектами. Изменения кода, фотографий и документов будут автоматически передаваться в обе стороны. Новые проекты внутри общей папки тоже попадут в синхронизацию.

На компьютере общая папка уже существует:

```text
C:\Users\USER\Documents\Codex
```

На ноутбуке в этой инструкции используем:

```text
C:\Projects\Codex
```

Пути могут отличаться. Для соединения папок важен одинаковый Folder ID: all-projects.

Рабочие базы, зависимости и локальные настройки остаются отдельными на каждом компьютере. Для одинаковых пользователей, заявок и абонементов сайта нужен общий сервер с одной базой.

## Шаг 1. Скачать Syncthing на оба компьютера

1. Открой [страницу установщика для Windows](https://github.com/Bill-Stewart/SyncthingWindowsSetup/releases/latest).
2. Найди раздел Assets; если он свёрнут, раскрой его.
3. Скачай файл с расширением .exe. Source code скачивать не нужно.
4. Повтори на ноутбуке.

Это установщик сообщества, на который ссылается [официальная страница Syncthing](https://syncthing.net/downloads/).

## Шаг 2. Установить с автоматическим запуском

На обоих компьютерах:

1. Запусти скачанный установщик двойным щелчком.
2. Оставь установку для текущего пользователя — Current User.
3. Оставь включённым Start Syncthing automatically when logging on — запуск при входе в Windows.
4. Оставь включённым Start Syncthing after installation — запуск после установки.
5. На ноутбуке не включай Start automatically only if the computer is running AC power, чтобы синхронизация работала и от батареи.
6. Если установщик предлагает создание правила брандмауэра, разреши его.
7. Заверши установку.

## Шаг 3. Открыть настройки синхронизации

На каждом компьютере открой в браузере:

```text
http://127.0.0.1:8384/
```

Это панель Syncthing. Сам сайт SYNKRA открывается на порту 5174. Названия кнопок ниже приведены по-английски и по-русски; перевод может немного отличаться.

## Шаг 4. Связать компьютер и ноутбук

1. На ПК нажми Actions / Действия → Show ID / Показать ID.
2. Скопируй идентификатор устройства.
3. На ноутбуке нажми Add Remote Device / Добавить удалённое устройство.
4. Вставь ID компьютера, назови устройство «Компьютер» и нажми Save / Сохранить.
5. Теперь на ноутбуке открой Actions → Show ID и скопируй его идентификатор.
6. На ПК через Add Remote Device добавь этот ID с названием «Ноутбук».

Оба устройства должны знать ID друг друга. Предоставление доступа к папке включим после настройки исключений.

## Шаг 5. Если SYNKRA уже добавлена отдельно

Если ты ещё не добавлял папки в Syncthing, переходи к шагу 6.

Если раньше добавил отдельную папку SYNKRA:

1. Останови обмен для этой папки на обоих устройствах кнопкой Pause / Приостановить.
2. Убери её отдельную запись из Syncthing через Edit / Изменить → Remove / Удалить.
3. Сами файлы проекта в Проводнике сохрани.

Так общая папка не будет перекрываться с отдельной синхронизацией SYNKRA. Если на ноутбуке уже есть изменённая копия проекта в другой папке, сохрани её отдельно и сравни изменения перед дальнейшей работой. Для первого обмена ниже используем пустую папку ноутбука.

## Шаг 6. Добавить общую папку на ПК

1. Нажми Add Folder / Добавить папку.
2. Введи Folder Label / Название: Все проекты.
3. Введи Folder ID / Идентификатор: all-projects.
4. В поле Folder Path / Путь к папке вставь:

```text
C:\Users\USER\Documents\Codex
```

5. Во вкладке Advanced / Дополнительно установи Folder Type: Send & Receive / Отправка и получение.
6. Во вкладке Sharing / Предоставление доступа пока не отмечай ноутбук.
7. Нажми Save / Сохранить.

Код и фотографии SYNKRA уже находятся внутри этой общей папки. Перемещать проект на ПК не нужно.

## Шаг 7. Добавить общую папку на ноутбуке

1. В Проводнике создай пустую папку C:\Projects\Codex.
2. В Syncthing нажми Add Folder / Добавить папку.
3. Название: Все проекты.
4. Folder ID: all-projects — точно такой же, как на ПК.
5. Folder Path: C:\Projects\Codex.
6. Folder Type: Send & Receive / Отправка и получение.
7. Предоставление доступа компьютеру пока не включай.
8. Нажми Save / Сохранить.

Не выбирай на ноутбуке папку с другой старой копией проекта для первого обмена: пустая папка позволяет получить текущую версию с ПК без смешивания старых файлов.

## Шаг 8. Настроить исключения на ОБОИХ устройствах

В Syncthing на ПК и на ноутбуке выполни одинаковые действия:

1. Открой папку «Все проекты».
2. Нажми Edit / Изменить → Ignore Patterns / Шаблоны исключений.
3. Вставь следующий текст целиком:

```text
!.dev.vars.example
!.env.example
node_modules
dist
.next
.vinext
.wrangler
.sites-runtime
.git
.codex
.agents
.dev.vars*
.env*
*.sqlite
*.sqlite-*
*.db
*.db-wal
*.db-shm
*.log
```

4. Нажми Save / Сохранить.
5. Проверь, что сделал это и на ПК, и на ноутбуке.

Правила без начального / действуют на совпадающие имена во всех вложенных проектах. Шаблоны .dev.vars.example и .env.example остаются доступными для настройки новых компьютеров.

Syncthing хранит эти правила в .stignore в корне общей папки. Этот файл сам не синхронизируется. При изменении правил обновляй их на обоих устройствах.

Ранее подготовленный .stignore внутри папки SYNKRA для общей папки не применяется. Сейчас правила нужно сохранить именно для папки «Все проекты».

## Шаг 9. Включить обмен

1. На ПК открой «Все проекты» → Edit → Sharing.
2. Отметь устройство «Ноутбук» и сохрани.
3. На ноутбуке открой «Все проекты» → Edit → Sharing.
4. Отметь устройство «Компьютер» и сохрани.
5. Оставь оба компьютера включёнными, Syncthing запущенным и дождись Up to Date / Актуально на обоих устройствах.

Папки уже созданы вручную с одинаковым ID, поэтому создавать вторую папку по предложению программы не нужно. Первый обмен может занять время: передаются фотографии и остальные файлы всех проектов. Последующие изменения передаются по мере обнаружения.

## Шаг 10. Проверить обе стороны

1. На ПК создай в C:\Users\USER\Documents\Codex файл проверка-синхронизации.txt.
2. Напиши в нём «Создано на компьютере» и сохрани.
3. Дождись появления файла в C:\Projects\Codex на ноутбуке.
4. На ноутбуке допиши «Изменено на ноутбуке» и сохрани.
5. Проверь, что новая строка появилась на ПК.
6. Удали проверочный файл и дождись исчезновения на втором устройстве.

Удаления тоже синхронизируются. Чтобы хранить прошлые версии файлов, изменённых или удалённых другим устройством, на обоих компьютерах можно включить Edit → File Versioning → Simple File Versioning.

## Шаг 11. Найти и открыть SYNKRA на ноутбуке

После синхронизации папка проекта на ноутбуке будет здесь:

```text
C:\Projects\Codex\2026-10-13\http-localhost-3000-http-localhost-3000\outputs\synkra
```

1. Для работы над кодом открывай эту папку проекта в редакторе.
2. Для запуска сайта установи [Node.js LTS](https://nodejs.org/en/download), если его ещё нет.
3. Запусти Start-SYNKRA.cmd из указанной папки.
4. Первый запуск установит зависимости и создаст локальную базу ноутбука.
5. Дождись сообщения «САЙТ ГОТОВ» и открой http://127.0.0.1:5174/.
6. Оставь окно запуска сайта открытым, пока пользуешься сайтом.

Пользователи, заявки и права администратора с ПК автоматически в локальную базу ноутбука не переносятся. Настройки .dev.vars на ноутбуке тоже отдельные; для админки используй инструкцию Админка.md внутри проекта.

Если запуск остановился с Invalid BOOTSTRAP_ADMIN_EMAIL, дождись передачи обновлённого scripts/configure-local-admin.mjs и запусти Start-SYNKRA.cmd снова. В старом скрипте пустое поле ошибочно захватывало следующую строку. В исправленной версии пустой адрес допускается и не блокирует запуск; для назначения прав владельца нужно вписать настоящий email локального аккаунта в .dev.vars.

## Шаг 12. Как работать дальше

1. На обоих компьютерах сохраняй изменения внутри соответствующей общей папки.
2. Новые проекты создавай внутри неё — они будут передаваться автоматически.
3. Перед переходом с ПК на ноутбук или обратно дождись «Актуально» на обоих устройствах.
4. Когда оба устройства включены, Syncthing работает и они могут соединиться, сохранённые изменения передаются автоматически. Если одно устройство выключено, обмен продолжится после подключения.
5. Не редактируй один файл одновременно на двух устройствах. При разных изменениях Syncthing может создать файл с sync-conflict в имени; версии придётся сравнить и объединить вручную.

## Почему база исключена

Syncthing синхронизирует файлы, но не объединяет записи двух SQLite-баз. Если на ПК появилась одна заявка, а на ноутбуке другая, обычный обмен файлами не превратит их в одну общую базу.

Кроме того, работающая база использует связанные файлы транзакций. Копирование в разные моменты может дать несогласованную копию. Для одинаковых пользователей, заявок и абонементов на обоих устройствах нужен один сервер с общей базой. Для разового переноса используется отдельная резервная копия и восстановление.

Синхронизация папок не публикует сайт в интернете.
